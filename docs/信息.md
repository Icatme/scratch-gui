# sb3 URL Loading Notes

## Key Entry Points and Locations
- `src/components/menu-bar/menu-bar.jsx:228`: `handleClickLoadFromUrl` prompts for a link when the "Load from URL" menu item is clicked and forwards the value to `onStartLoadingProjectUrl`.
- `src/lib/sb-file-uploader-hoc.jsx:76`: `handleStartLoadingProjectUrl` trims/validates the link, marks the upload source as URL, and dispatches `requestProjectUpload`.
- `src/lib/sb-file-uploader-hoc.jsx:168`: `handleFinishedLoadingUpload` fetches the remote `.sb3`, hands it to `vm.loadProject`, and completes the upload flow.

## URL Parameter Parsing and Follow-up Calls
- `src/lib/query-parser-hoc.jsx:18`: constructor parses `location.search`, detects tutorials, and records any project URL from the query string.
- `src/lib/query-parser-hoc.jsx:32` & `src/lib/query-parser-hoc.jsx:38`: `componentDidMount`/`maybeLoadProjectFromQuery` wait until the GUI is showing a project before invoking `onStartLoadingProjectUrl`.
- `src/lib/query-parser-hoc.jsx:47`: `getProjectUrlFromQuery` accepts `project_url`, `projectUrl`, `sb3`, `sb3_url`, or `sb3Url`, returning the first non-empty URL.

## Call Chains
- **Menu "Load from URL"**: `menu-bar.jsx:228 handleClickLoadFromUrl` -> `sb-file-uploader-hoc.jsx:76 handleStartLoadingProjectUrl` -> `sb-file-uploader-hoc.jsx:168 handleFinishedLoadingUpload` -> `vm.loadProject`.
- **URL Parameter Auto-load**: `query-parser-hoc.jsx:18 constructor` -> `query-parser-hoc.jsx:32/38 maybeLoadProjectFromQuery` -> `sb-file-uploader-hoc.jsx:76 handleStartLoadingProjectUrl` -> `sb-file-uploader-hoc.jsx:168 handleFinishedLoadingUpload` -> `vm.loadProject`.

## Debugging
- Edit `src/settings.json` and set `"projectUrlDebugEnabled"` to `true` (default) or `false` to control the instrumentation in `project-url-debug.js`.
- Use `window.downloadProjectUrlDebugLog()` to export the current trace as a Markdown file (`log.md`).
- Logs are also accessible via `window.__projectUrlDebugLog` (includes separate buckets for the menu and query chains).
